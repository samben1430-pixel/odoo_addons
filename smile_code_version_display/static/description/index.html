🔖 Code Version Display

Display your code version in the Odoo systray for easy identification!

🔀 v1.2.3

Features

  • Beautiful gradient badge in systray
  • Configurable via system parameter
  • Works with or without smile_upgrade
  • Perfect for DEV/QA/STAGING environments
  • Minimal performance impact
  • Easy integration with ribbon modules

Quick Setup

  1. Install the module
  2. Set system parameter code.version.display = True
  3. Set system parameter code.version = 1.2.3 (or use smile_upgrade)
  4. Refresh your browser
  5. See your version in the top bar!

The version badge appears in the top navigation bar

Use Cases

🔧 Development Environment

Quickly see which version you're testing without checking git or deployment logs.

🧪 QA Environment

Testers can easily report which version has bugs - no more confusion!

🚀 Staging Environment

Verify the correct version is deployed before promoting to production.

Integration

Works great with environment ribbon modules! Use both together:

  • Ribbon: Shows environment (DEV/QA/PROD)
  • Version Badge: Shows code version

Configuration

Enable via Settings → Technical → System Parameters:

  • code.version.display = True - Enable the badge
  • code.version = 1.2.3 - Set your version
